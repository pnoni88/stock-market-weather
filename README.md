# 📈 시장 날씨 (Stock Market Weather)

오늘의 주식 시장 분위기를 날씨로 표현해주는 웹 앱입니다.

| 날씨 | 조건 |
|------|------|
| ☀️ 맑음 | 상승 종목 75% 이상 |
| 🌤 구름 조금 | 상승 종목 55~75% |
| ⛅ 흐림 | 보합권 (상승 35~55%) |
| 🌧 비 | 하락 우위 (상승 12~35%) |
| ⛈ 폭우 | 상승 종목 12% 이하 |
| 🌪 공포 | 지수 -3% 이상 급락 |

## 기능

- **📡 실시간 KOSPI 모드**: 네이버 증권 시세 기반 — 코스피 지수와 시가총액 상위 30개
  종목의 등락을 60초마다 갱신해 날씨로 판정합니다.
- **🔄 시뮬레이션 모드**: 가상 데이터로 시장 분위기가 천천히 오르내립니다.
- **시나리오 버튼**: 맑음/흐림/폭우/공포 상태를 즉시 체험할 수 있습니다.

## 실행

정적 파일 하나(`index.html`)로 동작합니다. 브라우저로 열거나 아무 정적 서버로 서빙하면 됩니다.

> ⚠️ 시세는 공개 CORS 프록시를 경유하며 지연/종가 데이터일 수 있습니다.
> 투자 판단의 근거로 사용하지 마세요.
