# 📈 시장 날씨 (Stock Market Weather)

오늘의 주식 시장 분위기를 날씨로 표현해주는 웹 앱입니다.

| 날씨 | 조건 |
|------|------|
| ☀️ 맑음 | 상승 종목 75% 이상 |
| 🌤 구름 조금 | 상승 종목 55~75% |
| ⛅ 흐림 | 보합권 (상승 35~55%) |
| 🌧 비 | 하락 우위 (상승 12~35%) |
| ⛈ 폭우 | 상승 종목 12% 이하 |
| 🌪 공포 | 지수 -3% 이상 급락 |

## 기능

- **📡 실시간 KOSPI 모드**: 네이버 증권 시세 기반 — 코스피 지수와 시가총액 상위 30개
  종목의 등락을 30초(자체 서버) 또는 60초(공개 프록시)마다 갱신해 날씨로 판정합니다.
- **🔄 시뮬레이션 모드**: 가상 데이터로 시장 분위기가 천천히 오르내립니다.
- **시나리오 버튼**: 맑음/흐림/폭우/공포 상태를 즉시 체험할 수 있습니다.

## 실시간 시세를 받아오는 방식

브라우저는 보안 정책(CORS) 때문에 네이버 증권 API를 직접 호출할 수 없습니다.
그래서 중간에서 대신 받아 줄 곳이 필요하며, 페이지는 아래 순서로 시도합니다.

1. **자체 서버 `api/market`** (권장) — 같은 저장소의 함수가 서버에서 네이버를 조회합니다.
   Vercel에 배포하면 서울 리전(`icn1`)에서 실행되고 응답을 CDN에 20초간 캐시하며,
   내 컴퓨터에서는 `npm start`로 같은 함수를 실행합니다(아래 "내 컴퓨터에서 실행" 참고).
2. **공개 CORS 프록시** (비상용) — allorigins, codetabs, corsproxy.io.
   무료 제3자 서비스라 느리거나 막힐 수 있습니다. 예컨대 corsproxy.io는 운영 도메인에서
   쓰려면 유료 API 키가 필요하다고 안내합니다.

모두 실패하면 상태 표시 아래에 **경로별 실패 원인**이 나오고, 8초 → 16초 → 32초 → 60초 간격으로
자동 재시도합니다. 브라우저 개발자 도구 콘솔에도 같은 내용이 기록됩니다.

## 실행 · 배포

### Vercel 배포 (실시간 모드 권장 방식)

1. [Vercel](https://vercel.com/new)에서 이 GitHub 저장소를 Import 합니다.
2. 설정은 바꾸지 않고 Deploy 합니다. 빌드 과정은 없습니다. `index.html`은 정적 파일로,
   `api/market.js`는 함수로 자동 배포됩니다.

### 내 컴퓨터에서 실행 (실시간 모드)

`index.html`을 더블클릭해 열면 **실시간 시세가 거의 항상 실패합니다.** 파일로 연 페이지(`file://`)에는
자체 서버 `api/market`이 없어서, 남은 길인 무료 공개 프록시가 막히면 받을 방법이 없기 때문입니다.
대신 아래처럼 실행하세요(Node 20 이상, 설치할 패키지 없음).

```bash
npm start
```

터미널에 나온 주소 **http://127.0.0.1:3000** 을 브라우저로 엽니다. 이 서버(`server.js`)는 `index.html`과
`api/market`을 함께 제공하며, `api/market`은 Vercel에 배포되는 것과 같은 함수입니다. 네이버 조회가 내
컴퓨터에서 서버 대 서버로 이뤄지므로 CORS 문제도, 공개 프록시도 필요 없습니다.
3000번 포트가 사용 중이면 `npm start -- 3001`처럼 다른 포트를 지정합니다. 종료는 `Ctrl+C`입니다.

시뮬레이션 모드는 HTML 파일을 직접 열어도 동작합니다.

### 테스트

```bash
npm test
```

`api/market.js`의 정상 응답·네이버 오류·시간 초과·비JSON 응답 처리와, `server.js`가 페이지와
`/api/market`을 같은 출처로 제공하는지를 확인합니다(Node 20 이상, 설치할 패키지 없음).

> ⚠️ 네이버 증권의 공개 문서화된 API가 아니므로 예고 없이 바뀌거나 막힐 수 있으며,
> 지연/종가 데이터일 수 있습니다. 투자 판단의 근거로 사용하지 마세요.
